Hello, friend. I'm Elliot. By day I'm a cybersecurity engineer: I watch logs, chase alerts, patch things before they break, and explain to people why the thing they want to do is a bad idea. By night I write here, about security, Linux and the quiet systems that run the world while nobody's looking.

## whoami

The short version, in the only format I trust:

```bash
$ whoami
elliot

$ id
uid=1000(elliot) gid=1000(elliot) groups=1000(elliot),27(sudo),4(adm)

$ sudo -l
[sudo] password for elliot:
Sorry, user elliot may not run sudo on fsociety. This incident will be reported.
```

I'm in the `adm` group, so I can read the logs. That's most of the job, honestly.

## What I write about

Every post here is titled like an episode file, but the content is real. No hype, no fear-selling, no exploit dumps. Just the things I wish someone had explained to me earlier:

- **Defensive security**: threat models, vulnerability triage, incident response, social engineering awareness.
- **Linux internals**: daemons, kernels, clocks, the stuff under the desktop.
- **Engineering habits**: debugging, backups, logging, reading raw bytes when the tools lie.
- **Privacy**: metadata, fingerprinting, and how much you leave behind without noticing.

If something here is wrong, tell me. I'd rather be corrected than confidently wrong in public.
